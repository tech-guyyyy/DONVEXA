# DONVEXA Brand Assets and Initial Usage Guide

## Approval status

The supplied DONVEXA logo is approved for use. The package includes recoloured transparent PNG exports, cropped to remove excess canvas padding. The design itself is retained: the wordmark with its play-triangle details.

## Initial palette

- **Charcoal:** `#292521` — primary wordmark, headings and dark text.
- **Warm ivory:** `#F6F1E8` — reversed wordmark on dark backgrounds and optional warm surface.
- **Muted copper:** `#B86F4B` — accent details, links/active states used sparingly.
- **Storefront background:** warm white/ivory.
- **Admin background:** near-black/graphite; use the reversed logo.

## Files

- `DONVEXA_Logo_Transparent.png` — primary charcoal wordmark with copper accents; use on light surfaces.
- `DONVEXA_Logo_Light_Transparent.png` — warm-ivory wordmark with copper accents; use on dark surfaces.
- `DONVEXA_App_Icon_512.png` — square icon export, 512 × 512.
- `DONVEXA_App_Icon_192.png` — square icon export, 192 × 192.

## Rules

- Keep the background transparent where the asset is intended to sit over a UI surface.
- Do not stretch, rotate, add glow, add shadows, add a background pattern, or add the DONVEXA name beneath the icon.
- Use the primary logo on the light storefront and the reversed logo on the dark admin dashboard.
- Maintain sufficient clear space and do not shrink the full wordmark until it becomes illegible; use the icon asset for very small placements.
- Treat these hex values as the approved initial palette for this planning package. Check actual contrast in UI implementation, especially for small text and interactive states.
- Exact font pairing is still undecided.
