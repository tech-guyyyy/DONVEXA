# DONVEXA Version 1 Handoff Package

This package contains six coordinated planning/implementation specifications plus a plain-language project overview and brand assets. It is a planning handoff, not authorization to code, deploy, or use live payment credentials.

## Documents

1. `01_Product_Requirements_Document.md` — product goals, scope, journeys, acceptance criteria, open decisions.
2. `02_Technical_Requirements_and_Architecture.md` — proposed stack, boundaries, security and deployment architecture.
3. `03_UI_UX_Design_Specification.md` — customer storefront and admin design direction.
4. `04_Database_and_Data_Model_Specification.md` — entities, relationships and state model.
5. `05_Business_Logic_and_Integration_Specification.md` — payment, delivery, discounts, email and integration rules.
6. `06_Implementation_Plan_and_Test_Checklist.md` — milestones, gates and tests.
7. `07_Project_Overview_and_Toolkit.md` — plain-language summary of what DONVEXA is, what it contains and what each tool does.
8. `brand-assets/` — approved logo variants and app icon exports.
9. `brand-assets/DONVEXA_Brand_Guidelines.md` — initial palette and usage rules.

## Current proposed stack

Next.js + TypeScript, Vercel, Supabase, GitHub and Paystack. Email provider, analytics provider, development environment and several business policies remain undecided; see the overview and the open-decision sections in the specifications.

## Brand

The DONVEXA logo is approved. Initial palette: charcoal `#292521`, warm ivory `#F6F1E8`, muted copper `#B86F4B`. The primary logo is intended for light surfaces; the reversed logo is intended for dark admin surfaces. Exact font pairing is still open.
